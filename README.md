## Sobre mim

Engenheiro de Software com experiência prática em desenvolvimento backend e full stack. Crio APIs, integrações, painéis web e plugins Java para Minecraft, com foco em qualidade, performance e manutenção.

Sou fundador da **Leaf Delta / LeafPlugins**, um ecossistema de produtos digitais com mais de **1.000 usuários** e **1.200 licenças emitidas**.

## Stack

**Java**, **Spring Boot**, **TypeScript**, **Node.js**, **React**, **Next.js**, **APIs REST**, **PostgreSQL**, **MySQL**, **SQLite**, **Docker** e **Git**.

## Projetos

- **Leaf Delta / LeafPlugins:** plataforma para venda, licenciamento e atualização de produtos digitais.
- **SocioLudo Digital:** jogo educacional desenvolvido com Unity, C# e SQLite.
